Presentación del Proyecto ALTUM

Se trata de la página web del Banco ALTUM. Para tener una base y así empezar el Proyecto 1 de IAWE, se desarrollan los html, css y bootstrap con la ayuda de la IA.

Como propósito, es poder simular un servicio Bancario sencillo y poder usarlo como idea para el proyecto final intermodular.

Respecto a la práctica:
Creación del html base : Incluye Navbar y Footer (base.html)

TODOS LOS APARTADOS SE ENCUENTRAN EN "¿QUÉ NECESITAS?"

  1. Listado de elementos: En /listaUsuarios = "VER USUARIOS" (listado.html)
  2. Página de detalle: En /listaUsuarios/num_usuarioID = FILTRAR USUARIO (detalle.html)
  3. Consulta mediante formulario: Formulario GET en /buscarUsuario = "BUSCAR CONSULTA" (buscar.html)
  4. Añadir nuevos elementos: "Hazte Cliente" (en /registro) o "ABRIR CUENTA" (registro.html)
  5. Validación: Dentro de la función registro(), el formulario valida si es mayor de 18, campos obligatorios y rango de dinero
  6. Resumen/estadísticas : En /estadisticas = "ESTADISTICAS" (estadisticas.html)
  7. Página personalizada: "En /simulador = "SIMULADOR DE HIPOTECA" (simulador.html)
  8. Página personalizada (extra): Añadí el html del formulario de contacto para no olvidarme de él en futuros cambios, aunque no está desarrollada. (contacto.html)
